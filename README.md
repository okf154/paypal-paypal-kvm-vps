## 搬瓦工支持哪些支付方式？

搬瓦工的常见下单支付方式包括：

- **PayPal**
- **Visa / Mastercard 信用卡或借记卡**
- **支付宝**
- **银联**

对于中国大陆用户，支付宝和银联通常更直接，不需要先准备一张可进行境外线上支付的 Visa 或 Mastercard。PayPal 则更适合已经有 PayPal 账户、希望使用美元余额或绑定国际卡付款的用户。

不过，支付方式可能会根据订单类型、地区、风控状态和付款页面变化。最稳妥的判断方式，是进入具体套餐的结账页，查看实际显示的支付选项。不要把几年前教程中出现过的微信支付、比特币或其他方式默认当成当前仍然可用。

### 支付方式对比

| 支付方式 | 适合谁 | 主要特点 | 需要留意 |
| --- | --- | --- | --- |
| 支付宝 | 中国大陆用户 | 通常以人民币完成付款，操作简单 | 具体是否出现以及支付稳定性，以当前结账页为准 |
| 银联 | 持有银联卡的用户 | 可使用银联借记卡或信用卡 | 部分卡片可能受到发卡行境外支付限制 |
| PayPal | 海外用户、已有 PayPal 账户的用户 | 账户体系成熟，可用余额或绑定资金来源 | 汇率和 PayPal 自身换汇选项可能影响最终成本 |
| Visa / Mastercard | 持有国际卡的用户 | 直接输入卡片信息完成支付 | 可能被发卡行拦截境外商户交易 |

如果你只是想买一台入门 VPS，支付宝或银联通常更省事；如果你还要给账户余额充值，PayPal 和信用卡往往更值得优先尝试，原因在于**新订单付款和账户余额充值并不一定支持完全相同的支付方式**。

## 支付宝能不能买搬瓦工？

可以尝试。当前搬瓦工相关结账流程中，支付宝通常作为单独支付选项出现。选择后，页面一般会跳转到支付宝支付界面或显示二维码，再使用支付宝 App 完成付款。

实际操作流程通常是：

1. 选择 VPS 套餐和付款周期。
2. 填写账户信息并确认订单金额。
3. 在订单页面查看可用支付方式。
4. 选择支付宝。
5. 根据页面提示扫码或登录支付宝完成付款。
6. 返回搬瓦工客户区，确认账单状态变为已支付。
7. 在服务列表中查看 VPS 和 KiwiVM 控制面板入口。

支付宝的优势是不用处理国际卡验证，也不需要先把人民币兑换成美元再付款。但如果支付后订单仍显示未支付，不要马上重复付款。先查看支付宝交易记录、搬瓦工账单状态和邮箱通知，再决定是否提交工单。

另外，支付宝是否能用于**账户余额充值**，要单独看充值页面。新订单结账页支持某种方式，并不代表“Add Funds”页面也支持同一种方式。

## 银联卡能不能付款？

银联是搬瓦工面向中国用户时经常被关注的支付方式。持有中国银行发行的银联借记卡或信用卡时，可以在结账页面选择 UnionPay，再按照银联页面提示完成付款。

银联支付比较适合以下情况：

- 没有 Visa 或 Mastercard；
- 不想注册或使用 PayPal；
- 希望直接使用人民币资金；
- 账户余额不足，需要直接支付当前账单。

如果银联支付失败，常见原因不一定是搬瓦工拒绝银联，也可能包括：

- 银行卡未开通境外线上交易；
- 银行风控拦截；
- 单笔或单日交易限额；
- 账单地址、姓名或卡片信息不匹配；
- 浏览器拦截了支付页面跳转；
- 订单触发了额外人工审核。

遇到这种情况，可以先换一个浏览器或网络环境重新打开账单，也可以改用支付宝或 PayPal。不要连续提交多笔订单，否则后续退款和账单核对会更麻烦。

## PayPal 会自动扣款吗？

不会。搬瓦工官方知识库明确说明，平台不会自动扣除客户绑定的信用卡或 PayPal 付款方式，也不会保存这些支付信息用于自动扣款。续费账单会在续费日期前生成，用户需要主动付款；如果账户余额足够，余额可以自动用于支付账单。

这意味着搬瓦工的续费逻辑和很多 SaaS 服务不一样：

- 绑定 PayPal 不代表以后会自动扣 PayPal；
- 保存过信用卡信息，也不代表平台会按期扣卡；
- 续费账单通常会提前生成；
- 如果账户余额足够，系统可以从余额中支付；
- 如果余额不足，用户需要在账单到期前手动付款；
- 长时间不付款，服务可能被暂停。

官方知识库说明，续费账单通常会在续费日期前 7 天生成。如果账户余额不足，平台会通知用户处理账单；超过规定期限仍未付款，服务可能被暂停。

所以，“搬瓦工不自动扣款”并不等于“搬瓦工完全不会自动续费”。更准确的说法是：**平台不会直接从 PayPal 或银行卡自动扣款，但账户余额足够时，余额可以自动支付续费账单。**

## 账户余额充值要注意什么？

账户充值和新订单付款是两个不同场景。

新买 VPS 时，结账页可能显示支付宝、银联、PayPal 和信用卡等选项；但进入客户区给账户余额充值时，可用方式可能减少。已有资料和实际用户流程普遍反映，余额充值更常见的是 PayPal 和信用卡，支付宝、银联不一定会在充值页面出现。

如果你希望未来续费时不必临时处理账单，可以这样安排：

1. 使用 PayPal 或 Visa / Mastercard 给账户余额充值。
2. 充值金额至少覆盖下一次续费。
3. 确认服务的 Renewal 状态仍然开启。
4. 在客户区检查余额和账单。
5. 续费前查看邮箱，确认系统已生成账单。

如果你更习惯使用支付宝或银联，也可以不充值余额，在续费账单生成后手动支付。这样资金不会提前放在账户里，但需要自己记得处理续费日期。

## 搬瓦工付款失败怎么办？

付款失败时，先区分是“支付平台失败”还是“搬瓦工账单没有更新”。

### 支付页面直接报错

先检查银行卡是否开通境外支付，或者换用另一种支付方式。银联卡、Visa、Mastercard 和 PayPal 的风控链路不同，某一种失败不代表其他方式也不可用。

### 钱已经扣了，但账单仍显示未支付

先不要重复付款，按下面顺序检查：

1. 保存支付平台的交易号或付款截图。
2. 等待几分钟并刷新搬瓦工客户区。
3. 检查邮箱中是否收到付款确认。
4. 查看账单状态是否变为 Paid。
5. 如果仍未更新，提交工单并附上交易号。

重复支付会让退款、人工核对和订单开通变得更复杂。尤其是 PayPal 支付完成后，不要立刻关闭所有页面，先确认是否已经返回搬瓦工客户区。

### 订单被风控审核

新账户、使用 VPN 或代理网络、付款地区与账户资料不一致，都可能触发额外审核。此时继续重复下单通常没有帮助，按照平台邮件要求补充信息，或者换一种付款方式，往往更有效。

## 常见问题

### 搬瓦工支持微信支付吗？

不能把微信支付视为当前稳定可用的标准选项。旧教程中可能出现过微信支付或其他方式，但支付页面会变化，最终应以当前订单结账页显示为准。

### 搬瓦工支持加密货币吗？

不要根据第三方文章直接判断。当前是否提供加密货币支付，应以实际结账页面为准。官网公开资料重点说明的是信用卡、PayPal 和账户余额的扣款规则，并没有在知识库中把加密货币列为固定支付方式。

### 支付宝付款后可以退款到哪里？

如果订单符合退款政策，退款通常会回到原支付渠道。搬瓦工官方公开说明提供 30 天退款政策，但具体适用条件仍以服务条款和订单情况为准。官网首页也将 30 天退款政策列为服务承诺之一。

### 付款后多久能开通 VPS？

官网将 VPS 标记为支持即时开通，但实际速度仍取决于库存、付款状态和风控审核。账单显示已支付后，可以进入客户区查看服务；如果长时间没有开通，提交工单比重复付款更合适。

### 搬瓦工适合新手吗？

它提供 KiwiVM、系统重装、root 权限、rDNS 和快照等基础控制功能，但服务本身是自管理模式。也就是说，系统配置、网站部署、防火墙、程序升级和安全维护通常需要用户自己完成。官网明确将服务描述为 self-managed。
